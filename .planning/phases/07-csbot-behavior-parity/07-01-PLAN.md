<objective>
Define immutable WorldSnapshot, visible/audible observations, confidence,
memory age, and explicit uncertainty contracts without engine types.
</objective>

<tasks>

### Task 1: Write failing snapshot and perception tests

Cover finite/bounded actor, entity, sound, and contact values; map/round/tick
identity; visible versus unknown contacts; confidence and observation age;
memory expiry; duplicate-frame rejection; and actor-specific generation
invalidation. Assert that hidden or unobserved state cannot be represented as
confirmed truth.

### Task 2: Define immutable observation records

Add bounded value records for WorldSnapshot, actor observations, audible
events, contact confidence, uncertainty, and memory samples. Keep all
collections capped, use stable IDs and generation stamps, and return explicit
validation results. Do not expose `edict_t`, SDK vectors, callbacks, or
mutable pointers.

### Task 3: Implement deterministic perception assembly

Accept only supplied observations, normalize confidence/age within configured
bounds, preserve Unknown separately from observed absence, and publish a
snapshot without retaining adapter storage. Reject non-finite, stale,
duplicate, or over-limit input without partial publication.

### Task 4: Verify isolated integration

Register the sources and focused tests in CMake and the source manifest. Run
focused and complete Windows/Linux x86 Core/Metamod tests plus SDK-boundary
and source-format checks. Keep live visual/sound acceptance open for Phase 8.

</tasks>

<must_haves>

- Hidden information is never converted into a confirmed contact.
- Snapshot and memory values are immutable, bounded, finite, and generation
  scoped.
- Perception output is observation data, not a combat or movement success.

</must_haves>
