<objective>
Model bounded weapon inventory, aiming, firing, reload, ammunition, damage,
and combat intents with explicit engine feedback boundaries.
</objective>

<tasks>

### Task 1: Write failing weapon and combat tests

Cover inventory slot bounds, weapon availability, ammo and reload states,
finite aim targets, view-angle limits, fire cooldown, friendly-fire risk,
damage/death observations, invalid target uncertainty, and stale actor
generation. Assert that aim/fire/reload intents never imply engine success.

### Task 2: Define weapon and combat value contracts

Add SDK-free records for weapon identity, ammo, cooldown, target belief,
aim intent, fire intent, reload intent, damage observation, and combat result.
Bound angles, rates, list sizes, and confidence. Keep current enemy state
observation-scoped and never read private GameDLL values.

### Task 3: Implement deterministic combat intent selection

Select legal weapons and actions from supplied inventory/observation values,
reject unsafe or unknown targets, enforce cooldown and ammo constraints, and
return explicit recovery/no-action results. Preserve actor and snapshot
stamps through every intent.

### Task 4: Verify no dispatch coupling

Register sources/tests, run focused and complete x86 suites, inspect Core
include boundaries, and confirm `CommandReceipt`, `RunPlayerMove`, and engine
weapon calls remain adapter-owned.

</tasks>

<must_haves>

- Unknown target or weapon feedback fails closed.
- Intent emission is separate from firing, damage, ammo, and death success.
- Combat decisions are finite, bounded, and actor-specific.

</must_haves>

<verification>

1. Observe weapon/combat tests fail before implementation.
2. Run Windows/Linux x86 offline and Metamod regression suites.
3. Record live combat parity as unverified until Phase 8.

</verification>
