<objective>
Implement actor/team-scoped radio, chatter, report, assignment, and
information-boundary contracts without converting uncertainty into certainty.
</objective>

<tasks>

### Task 1: Write failing team and radio tests

Cover team reports, explicit observations, tactical proposals, assignments,
radio categories, cooldowns, recipient limits, confidence/age, unknown
information, actor generation changes, and round reset. Assert that a report
does not become a confirmed shared fact and radio intent does not imply a
delivered message.

### Task 2: Define communication contracts

Add bounded value records for team report source, recipient scope, report
kind, confidence, expiry, radio/chatter category, priority, and send intent.
Require stamps and explicit visibility of Unknown/Unverified data. No global
singleton or hidden shared memory is permitted.

### Task 3: Implement deterministic communication selection

Merge only permitted actor/team reports with age and confidence rules,
preserve uncertainty, enforce cooldown/list bounds, and emit explicit radio
intents. Reject stale reports and return recoverable results for unavailable
communication paths.

### Task 4: Verify information boundaries

Register sources/tests, run complete x86 suites, inspect Core dependencies,
and verify no hidden enemy coordinates, engine message calls, or dispatch
receipt claims cross the Core boundary.

</tasks>

<must_haves>

- Team communication never fabricates omniscient certainty.
- Reports and radio intents remain actor/team/generation scoped.
- Message emission is not message delivery or gameplay success.

</must_haves>

<verification>

1. Observe communication tests fail before implementation.
2. Run Windows/Linux x86 portable and Metamod regression suites.
