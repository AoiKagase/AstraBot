<objective>
Add deterministic SDK-free map, round, and slot-generation state, then wire
the public lifecycle callbacks so stale state is invalidated at every
boundary without retaining edict pointers in Core.
</objective>

<context>
Read `02-CONTEXT.md`, `02-01-SUMMARY.md`, the approved design, and
`C_CPP_REFACTOR_RULES.md`. The Core contract must use value types and stable
generation numbers only. The adapter may translate SDK callback arguments to
slot numbers, but Core must not include `edict_t`, `Vector`, or a function
table. Do not attempt to discover private ReGameDLL round objects.
</context>

<tasks>

### Task 1: Write the failing generation tests

**Type:** test
**Files:** `tests/lifecycle_generation_tests.cpp`, `CMakeLists.txt`

**Action:** Define tests for a fresh session, map activation, explicit round
start, frame-reset observation, map deactivation, slot connect/disconnect,
slot reuse, and current-token validation. Assert monotonic generation
changes, invalidation of old map/round/slot tokens, and safe idempotence of
repeated teardown. Use independent expected values rather than reusing Core
constants in assertions.

**Verify:** Build/run before implementing `LifecycleSession`. The test must
fail because the requested state API is absent, not due to test setup errors.

**Acceptance criteria:** Every required invalidation rule has a minimal red
test and a clear behavior name.

### Task 2: Implement the SDK-free lifecycle session

**Type:** implementation
**Files:** `include/astrabot/runtime/lifecycle.hpp`,
`src/core/runtime/lifecycle.cpp`, `CMakeLists.txt`

**Action:** Implement a bounded `LifecycleSession` value-oriented contract
with `MapGeneration`, `RoundGeneration`, and per-slot `EntityGeneration`.
Expose explicit operations for `activateMap`, `beginRound`,
`observeFrame`, `deactivateMap`, `connectSlot`, `disconnectSlot`, and
current-token checks. Use a named invalid-generation value and checked
increment behavior so wraparound cannot make an old token current. Return
explicit result/status values; do not throw. Keep the contract deterministic
and independent of wall-clock time, randomness, or SDK layout.

**Verify:** Run the lifecycle tests until green, then run all existing
portable tests. Confirm the public header is self-contained and compiles
under C++14.

**Acceptance criteria:** Old map, round, and slot tokens cannot validate
after their corresponding lifecycle boundary; repeated disconnect/deactivate
is harmless.

### Task 3: Wire lifecycle callbacks to the Core session

**Type:** implementation
**Files:** `src/adapter/metamod/plugin_runtime.hpp`,
`src/adapter/metamod/plugin_runtime.cpp`

**Action:** On `ServerActivate`, activate a new map session before returning
through Metamod. On `ServerDeactivate`, invalidate the session before the
GameDLL teardown continues. On `StartFrame`, pass only a small value
observation (frame count/time monotonicity) to Core; a detected frame reset
must invalidate the current round/session according to the tested contract.
On `ClientPutInServer` and `ClientDisconnect`, obtain the stable slot index
through the public engine boundary when available and update slot
generation. If the index cannot be obtained safely, emit a diagnostic and
do not manufacture an identity. Keep callbacks main-thread-only and make
them no-ops after detach.

Provide an explicit adapter-only round-boundary entrypoint for later public
event translators. Do not pretend that private GameDLL round state is
observable in this phase; record the source of each round transition for
diagnostics.

**Verify:** Extend the adapter test to call the published callbacks in valid,
invalid, map-change, round-boundary, disconnect, and post-detach orders.
Run Windows/Linux x86 focused tests and inspect generation traces.

**Acceptance criteria:** Hook order is safe, map/round/slot generation
changes are observable, and stale state is invalidated without SDK types
crossing the Core boundary.

### Task 4: Refactor and verify source format

**Type:** refactor
**Files:** all C/C++ files changed by this plan

**Action:** Keep lifecycle transitions in the smallest responsible units,
remove duplicated state mutation, name all protocol/limit constants, and
apply every applicable rule in `C_CPP_REFACTOR_RULES.md`.

**Verify:** Run focused and portable tests, `git diff --check`, and checks
for tabs/LF/BOM/trailing whitespace/newline. Confirm the implementation does
not add a Nav write path or a private GameDLL dependency.

**Acceptance criteria:** The Core session and adapter wiring are readable,
deterministic, and independently testable.
